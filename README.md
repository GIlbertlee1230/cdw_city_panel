# ICCBEI supplementary materials

Updated 10 November 2026.

## Download

The current three-part supplementary package is [the complete ZIP](ICCBEI_Supplementary_Materials_20261110.zip). Verify it using [the SHA256 checksum](ICCBEI_Supplementary_Materials_20261110.zip.sha256).

```bash
shasum -a 256 -c ICCBEI_Supplementary_Materials_20261110.zip.sha256
unzip ICCBEI_Supplementary_Materials_20261110.zip
```

## Contents

- Part0 includes 95 raw government documents and their source index, screening-rule code, an English Word prompt document and four JSON schemas, the 120-item accuracy evaluation and 60-item exclusion audit, and the three-column C&DW generation panel.
- Part1 provides the six-column predictor panel.
- Part2 provides the training code, estimator definitions, explicit parameter grid and recorded dependencies.

The package README describes units, temporal validation, evaluation scope and reproduction commands. The outcome panel contains 133 city-year records, including the early Guangzhou/Shenzhen history needed for lagged inputs. The predictor panel contains 252 records. Evaluation tables retain original evidence and use Times New Roman with unfilled cells.

The earlier `cdw_city_panel_v1.0.0.zip` remains an archived distribution. Use the dated ZIP above for the current supplementary materials.
